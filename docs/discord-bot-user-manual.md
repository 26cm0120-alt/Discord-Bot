# Discord Bot ユーザー向け取扱説明書

読み上げBotとコミュニティ機能の使い方をまとめたガイドです。Discordに慣れていない方も、まずは「最初にすること」からご覧ください。

対象：サーバーメンバー、サポーターロール、サーバー管理者  
更新日：2026年11月5日

---

## 1. このBotでできること

- `/join` を実行した聞き専チャンネルと、Botが接続しているVC内チャットのメッセージを読み上げます。
- 読み上げる声や速度を自分用に変更できます。
- 募集パネルからゲームの募集や3対3トーナメントを作成し、参加表明できます。
- 設定されたチャンネルに、ゲームの話題を週1回投稿します。
- 月間ステージ予定や誕生日のお知らせを確認できます。

## 2. 最初にすること

### 読み上げを使う

1. Botの接続先にしたいボイスチャンネルに自分が参加します。
2. 聞き専チャンネルのメッセージも読み上げたい場合は、その聞き専チャンネルで `/join` を実行します。VC内チャットだけを読み上げたい場合は、VC内チャットで実行します。
3. Botが接続したら、選んだ聞き専チャンネルと接続中VC内チャットのメッセージが読み上げられます。

読み上げ対象は `/join` を実行した場所で決まります。聞き専チャンネルで実行した場合は、そのチャンネルと接続中VC内チャットだけが対象です。ほかの聞き専チャンネルやVCのチャットは読み上げません。読み上げ元を切り替えるときは、希望する聞き専チャンネルまたはVC内チャットで `/join` を実行し直してください。

### コマンドを探す

Discordの入力欄に `/` を入力すると、使えるスラッシュコマンドが表示されます。`/help` ではBotのコマンド一覧を確認できます。

Botのコマンドやボタン操作への返答は、実行したチャンネルに表示され、ほかのメンバーも見られます。個人設定の確認や変更結果も公開されるため、必要に応じて人の少ないチャンネルで実行してください。

## 3. 読み上げの操作

- `/join`：自分が参加しているボイスチャンネルにBotを接続します。実行したチャンネルも読み上げ元として選択します。
- `/leave`：Botを切断します。BotがいるVCの参加者か、サーバー管理者が実行できます。
- `/skip`：再生中の読み上げを飛ばします。BotがいるVCの参加者が実行できます。
- `/queue`：待ち件数と直近の読み上げ時間を表示します。
- `/say text:<文章>`：入力した文章を読み上げます。読み上げ待ちに追加されます。
- `/status`：BotのVC接続、音声エンジンの状態などを確認します。
- `/ubw`：登録済みのUBW音声を接続中のVCで再生します。音量は通常の読み上げより小さい10%です。
- `/cumulo`：登録済みの「キュムロニンバス」音声を接続中のVCで再生します。音量は10%です。

`/ubw` と `/cumulo` は、Botが接続しているVCに自分も参加しているときに使えます。音声素材はBot運営者がローカルに登録するため、公開リポジトリからBotを導入しただけでは再生素材は含まれません。

VCにBot以外のユーザーがいなくなると、Botは自動で切断し、読み上げ待ちを消去します。再利用するときはVCに入り `/join` を実行してください。

Botが別のVCで使用中の場合、接続先を変更できるのはサーバー管理者です。同じVCで `/join` を実行し直すと、VCへの接続を維持したまま読み上げ元を切り替えます。

## 4. 自分の読み上げ音声を調整する

- `/speaker speaker:<話者>`：話者を名前で検索して変更します。
- `/setvoice speaker:<話者> speed:<速度> pitch:<高さ>`：話者、速度、高さを調整します。指定した項目だけ変更できます。
- `/voice`：現在の自分の話者や音声設定を確認します。
- `/voices page:<番号>`：VOICEVOXの話者一覧をページごとに表示します。
- `/supiki enabled:true`：自分の読み上げをスピキ風モードにします。通常音声に戻すには `enabled:false` を指定します。
- `/supiki-language language:auto|ja|ko`：スピキモードで使う言語を選びます。この設定はGPT-SoVITSが有効な場合に使われます。

話者や速度の設定はユーザーごとの設定ですが、Bot再起動後に初期化される項目があります。`/voice` で現在の状態を確認してください。

## 5. ゲーム募集を作成・参加する

### 募集を作成する

1. 募集を出したいチャンネルで `/community panel` を実行します。
2. 表示された「募集を作る」ボタンを押します。
3. ゲーム名、日時、募集人数、参加しやすさ、補足を入力して送信します。

募集人数には主催者を含めます。参加しやすさは「初心者歓迎」「誰でも」「経験者向け」のいずれかを入力してください。補足欄には、聞き専OK、途中参加OK、遊びたいモードなどを書けます。

募集パネルは全メンバーが設置できます。同じチャンネルで再度 `/community panel` を実行すると、既存のパネルが更新されます。募集チャンネル以外で実行すると、そのチャンネルにもパネルが設置されるので、募集用チャンネルで実行してください。

### 3対3トーナメントを開催する

1. 受付パネルを出したいテキストチャンネルで `/tournament create title:<イベント名>` を実行します。
2. 参加者は「参加 / 取り消し」ボタンを押します。参加上限は48人です。
3. 主催者が「抽選して開始」を押すと受付が終了し、Botが参加者をランダムに3人ずつのチームへ分けて、シングルエリミネーションのトーナメント表を作ります。
4. 各試合後、主催者かサーバー管理者が勝者チームのボタンを押すと、次の対戦が表示されます。

3人単位にならない場合、余った参加者は補欠として表示されます。試合結果を登録する前なら、主催者はチームを再抽選できます。チーム数が2の累乗でない場合は不戦勝が入り、優勝チームが決まるまで対戦が続きます。参加者・抽選結果はBotのローカル設定に保存されます。

### 募集に参加する

- 「参加 / 取り消し」ボタンで参加表明できます。同じボタンをもう一度押すと参加を取り消せます。
- 募集人数が埋まると、新しい参加者は参加できません。参加済みの人は満員後も取り消せます。
- 募集を締め切れるのは主催者かサーバー管理者です。
- Botは募集のために `@everyone` を通知しません。

## 6. 週次のゲーム話題

話題は設定された曜日・時刻に、指定チャンネルへ週1回投稿されます。設定や独自話題の管理ができるのはサーバー管理者と `/community access` で指定されたロールです。

### 独自の話題を登録する

- `/community prompts action:add text:<話題>`：話題を追加します。
- `/community prompts action:list`：登録した話題と番号を確認します。
- `/community prompts action:remove index:<番号>`：指定した話題を削除します。

独自の話題は最大30件まで登録でき、登録順に投稿されます。独自の話題が1件以上ある間は、Bot内蔵の話題は投稿されません。独自の話題をすべて削除すると、内蔵の話題に戻ります。

週次の自動投稿を止めるには `/community topics-clear` を実行します。投稿先・曜日・時刻の設定が解除され、独自の話題は保存されたままです。再開するには `/community topics` を設定し直してください。

### 内蔵の話題

独自の話題がない場合は、以下の候補を順番に使います。

1. 最近遊んで「これは人におすすめしたい」と思ったゲームは？どこが好きでしたか？
2. 初めて遊ぶ人に、最初の1時間で知っておくと楽になることを教えるなら？
3. 最近ゲームで一番笑った出来事は？
4. 今一緒に遊ぶ人を探しているゲームはありますか？初心者歓迎・聞き専OKなども気軽にどうぞ。
5. 時間を忘れて遊んだゲームは何ですか？どんなところに夢中になりましたか？
6. 好きな協力プレイや、みんなで遊ぶと盛り上がるゲームを教えてください。
7. 積んでいるゲーム、また始めたいゲームはありますか？一緒に遊ぶ人がいたら始められそう？
8. ゲーム内で好きな景色、音楽、キャラクターをひとつ紹介してください。
9. 初見でも参加しやすかったゲームや、遊びやすかった募集の雰囲気は？
10. 次の休みに誰かと遊ぶなら、何をやってみたいですか？
11. 最近覚えた小さなコツや、知って便利だった設定はありますか？
12. 対戦ゲームと協力ゲーム、今日はどちらの気分？理由もあればぜひ。

## 7. ステージ予定と誕生日

- `/season`：今月のステージ予定を確認します。`year` と `month` を指定すると別の月も確認できます。
- `/season year:<年> month:<月> schedule:<予定>`：月間予定を登録します。サーバー管理者と設定ロールが使えます。
- `/birthday set month:<月> day:<日> [channel:<チャンネル>]`：自分の誕生日を登録します。投稿先を省略すると、コマンドを実行したチャンネルが使われます。
- `/birthday list`：登録された誕生日を確認します。
- `/birthday remove`：自分の誕生日登録を削除します。

月間予定の登録時に通知先チャンネルを指定・変更できるのは管理者です。設定ロールのメンバーが予定を登録した場合は、既存の通知先が使われます。通知先が未設定の場合は、管理者に設定を依頼してください。

## 8. 権限と設定ロール

- `/community panel` は全メンバーが実行できます。
- `/community topics`、`/community topics-clear`、`/community prompts` はサーバー管理者か設定ロールが実行できます。
- `/community access role:<ロール>` は管理者が使用ロールを設定します。ロールを省略すると、話題設定は管理者のみになります。
- `/season` の月間予定の登録は、サーバー管理者か設定ロールが実行できます。通知先の変更は管理者のみです。

設定ロールがコマンド一覧に表示されても、サーバー管理者が設定したロールと異なる場合は実行できません。使用できないときは管理者に確認してください。

## 9. 困ったときは

**メッセージが読み上げられない**

- Botが `/join` でVCに接続しているか確認します。
- `/join` を聞き専チャンネルで実行したか確認します。VC内チャットで実行した場合は、聞き専チャンネルの投稿は読み上げません。
- `/queue` で待ち列を確認し、`/status` で音声エンジンの状態を確認します。

**募集パネルのボタンが動かない**

- Botに対象チャンネルの閲覧、メッセージ送信、埋め込みリンク送信の権限があるか確認します。
- Botが再起動された場合でも、設置済みパネルは通常そのまま使えます。問題が続く場合は、同じチャンネルで `/community panel` を実行して更新します。

**週次話題が投稿されない**

- 管理者または設定ロールに `/community topics` で投稿先・曜日・時刻が設定されているか確認します。
- Botに投稿先チャンネルの閲覧・メッセージ送信・埋め込みリンク送信権限があるか確認します。
- Botが停止していた場合、設定した曜日・時刻を過ぎてから起動すると投稿します。

**トーナメントの抽選を開始できない**

- 3対3には6人以上の参加が必要です。参加表明が6人以上あるか確認します。
- 抽選開始と勝者登録は、作成者かサーバー管理者が行えます。

**コマンドが見つからない**

- サーバー管理者にコマンドの登録状況と、自分のロール設定を確認してもらいます。
- Botの管理者向けコマンド登録・再起動直後は、Discord上の表示が更新されるまで少し待つ場合があります。

## 10. プライバシーについて

読み上げ対象のメッセージ本文は、Botのログやデータベースに保存しない設計です。話題、募集、トーナメントの設定はBotのローカル設定ファイルに保存されます。募集の参加者情報やトーナメントの参加者・抽選結果は表示・進行のために記録され、古い記録は期限や件数上限に応じて削除されます。`/ubw` と `/cumulo` の音声素材は運営者のローカルファイルに保存し、GitHubには公開しません。
